# Site Djiri Suplementos — como usar

Projeto React + Vite + Tailwind do site da Djiri Suplementos.
Cópia funcional restaurada em 05/08/2026 (backup do D:\Documents\djirisuplementos).

## Rodar localmente (para editar)

```
npm install
npm run dev
```

Abre em http://localhost:5173. Edite os arquivos em `src/` (o principal é `src/App.jsx`) e a página atualiza sozinha.

## Gerar a versão para publicar

```
npm run build
```

O resultado fica na pasta `dist/` — é essa pasta que se envia para a hospedagem.

## Estrutura

- `src/App.jsx` — todo o conteúdo/seções do site
- `src/index.css` — estilos (Tailwind)
- `src/assets/` — imagens
- `public/` — favicon e ícones
